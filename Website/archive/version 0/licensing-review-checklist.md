## UX / UI Checks

- [ ] CTA button uses high-contrast brand colors (orange `#F47920` on navy or white)
- [ ] Sticky CTA or CTAs repeated at multiple scroll points
- [ ] Mobile-first / responsive layout
- [ ] Minimal cognitive load — no section overloads with text
- [ ] Clear visual hierarchy (headline > subheading > body)
- [ ] Icons used for service categories (6.3, 6.5)
- [ ] Cards used for stats (6.2) and features
